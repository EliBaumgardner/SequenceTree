# TreeJev Agent Protocol

Generated from `treejev/flows/sequence_tree.json`. Do not edit this file: change the flow in TreeJev, which regenerates it, or run `treejev flow sync`.

TreeJev runs this project's flow on every Claude Code hook event. Its results reach you as context, tool denials and blocks. Follow each one.

## On every prompt (UserPromptSubmit)
- **Snapshot Source**: runs `"$TREEJEV_PLUGIN_RESEARCH_SUITE/bin/turn-scope.sh" --snapshot "$TREEJEV_SESSION"`; what it prints reaches you as context, a denial or a block.
- **Turn mode**: tree `sequence_tree_turn` reads the hook payload. Its action's directive reaches you as `[TreeJev: sequence_tree_turn | Final Action: <action>]` and is the decision: follow it, and do not run the tree again yourself. Then it becomes `deep` when -deep in the prompt; `skip`, `light`, `research` below confidence 0.5 becomes `code`.
- **Design-rule context**: runs `"$TREEJEV_PLUGIN_RESEARCH_SUITE/bin/design-rules.sh" --turn-context`; what it prints reaches you as context, a denial or a block. Only when turn.values.mode is one of code, deep.

## Before a tool runs (PreToolUse)
- **Owed checks**: runs the checks the turn's tree actions marked as owed. Checks: `edit-tools` (PreToolUse), `repeat` (PostToolUse), `tests` (Stop).

## After a tool runs (PostToolUse)
- **Owed checks**: runs the checks the turn's tree actions marked as owed. Checks: `edit-tools` (PreToolUse), `repeat` (PostToolUse), `tests` (Stop).

## When you stop (Stop)
- **Design-rule gate**: runs `"$TREEJEV_PLUGIN_RESEARCH_SUITE/bin/design-rules.sh" --hook stop`; what it prints reaches you as context, a denial or a block.
- **Readability gate**: runs `"$TREEJEV_PLUGIN_RESEARCH_SUITE/bin/readability.sh" --hook stop`; what it prints reaches you as context, a denial or a block.
- **Count Source lines**: runs `"$TREEJEV_PLUGIN_RESEARCH_SUITE/bin/source-lines.sh"`; what it prints reaches you as context, a denial or a block.
- **Change surface**: tree `change_surface` reads the output of `"$TREEJEV_PLUGIN_RESEARCH_SUITE/bin/systematic-check.sh" --state "$TREEJEV_SESSION"`. Its action's directive reaches you as `[TreeJev: change_surface | Final Action: <action>]` and is the decision: follow it, and do not run the tree again yourself. Only when turn.values.mode is deep and payload.stop_hook_active is false.
- **Change area**: tree `change_area` reads the output of `"$TREEJEV_PLUGIN_RESEARCH_SUITE/bin/systematic-check.sh" --state "$TREEJEV_SESSION"`. Its action's directive reaches you as `[TreeJev: change_area | Final Action: <action>]` and is the decision: follow it, and do not run the tree again yourself. Only when turn.values.mode is deep and payload.stop_hook_active is false.
- **Owed checks**: runs the checks the turn's tree actions marked as owed. Checks: `edit-tools` (PreToolUse), `repeat` (PostToolUse), `tests` (Stop). Only when payload.stop_hook_active is false.
- **Tree report**: shows the user every tree this turn ran and the action each reached.

## Agents without hooks
Antigravity, Cursor and other agents without lifecycle hooks run these trees themselves and follow the directive each returns:
- Before starting work: `treejev run sequence_tree_turn` (or the `treejev_evaluate` tool).
- Before finishing: `treejev run change_surface`.
- Before finishing: `treejev run change_area`.

## If TreeJev breaks
You will be told "TreeJev is broken: <reason>". Stop the task in progress and repair the cause, in TreeJev, this project's `treejev/` folder, or a plugin the flow names. Never remove or disable steps, trees or hooks to get past it. When you stop, TreeJev checks itself and hands the original request back. After three failed repairs it stops for the user.

## Signifier
The user is shown every tree a turn ran when the turn ends, so you do not need to print the signifier yourself.
